## Problem

For the Algorithm Design I course, Priscila developed an application to help
students organize assignments, exams, and academic deadlines in a single
place. Beyond completing the course project, she set a personal challenge:
build a full-fledged React application balancing usability, organization,
and maintainable code.

## What she did

Designed and developed the application using React, creating reusable
components and organizing the interface around the daily workflow of a
student rather than around technical features.

Made decisions about navigation, task organization, and responsive layouts
to keep the application easy to use across different screen sizes.

Used AI throughout development to brainstorm implementation approaches,
review code, troubleshoot issues, and improve documentation, while making
the final engineering decisions herself.

## Outcome

The project demonstrates her ability to take an idea from planning through
implementation, balancing technical requirements with user experience. It
also reflects how she uses AI to accelerate development without replacing
her own problem-solving process.
